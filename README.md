## Historial de Control de Versiones (Git)
* `git init` - Inicialización del entorno local.
* `git add` e `git commit` - Registro del progreso de la documentación.
* `git remote add` - Vinculación con el servidor de GitHub.
* `git push` - Despliegue de los registros en la nube.
